A mean-reversion dip-buy bot for Coinbase Wrapped BTC. It buys a 1% pullback off the 60-bar high and sells at 1.5% over cost, with a 1% stop and an 8% equity hard stop. Every order carries a unique client_id, which the race grader requires.

## Run it

```sh
python3 main.py
```
